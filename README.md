# Право olymp — подготовка к олимпиадам по праву

[![Сайт](https://img.shields.io/badge/сайт-pravolymp.ru-1f4e79)](https://pravolymp.ru)
[![GitHub Pages](https://img.shields.io/badge/GitHub%20Pages-live-24292e)](https://realfactchecknews-eng.github.io/hse-law-prep/)

Интерактивная образовательная платформа (SPA) для подготовки к олимпиадам по праву и поступлению на программу **«Юриспруденция»** в НИУ ВШЭ и другие вузы.

Контент формируется на основе учебников по ТГП и конституционному праву, презентаций курсов **«Общее дело»**, а также официальных сайтов олимпиад и вузов.

## Что умеет

- **Олимпиады** — карточки с информацией о 20 перечневых олимпиадах по праву и обществознанию: уровни РСОШ, льготы, сроки, форматы, ссылки.
- **ВУЗы** — 17 вузов, разбитых на категории (топовые, сильные юридические, региональные), с программами, вступительными, релевантными олимпиадами и примерными проходными баллами.
- **Темы** — 22 учебные темы по ТГП и конституционному праву.
- **Тесты** — 22 теста (по одному к каждой теме) с мгновенной проверкой и объяснениями.
- **Сравнение вузов** — подбор вузов по олимпиадам и льготам.
- **AI-юрист** — консультант на базе OpenRouter (`gpt-4o-mini`), помогает с теорией, олимпиадами и поступлением.
- **Telegram-бот** — напоминания о дедлайнах олимпиад.
- **Словарик** — юридические термины.
- **Пробники** — тренировочные задания.
- **Прогресс** — изученные темы, результаты тестов и история чата сохраняются в `localStorage`.
- **Тёмная тема** и адаптивный дизайн — работает на телефоне и компьютере.
- **Обратная связь** — форма предложений и отзывов.

## Стек

- **Фронтенд:** чистый HTML, CSS, JavaScript без сборки и фреймворков.
- **Хостинг:** GitHub Pages + Netlify.
- **AI-прокси:** Netlify Function (`netlify/functions/chat.js`) → OpenRouter API.
- **Бот:** Python + aiogram.
- **Вспомогательные скрипты:** Python (генерация данных, проверка сайтов олимпиад).

## Как добавить или изменить контент

Все учебные данные находятся в `js/data.js`:

- `olympiads` — информация об олимпиадах.
- `universities` — информация о вузах с категориями и проходными баллами.
- `topics` — учебные темы (`category`, `title`, `source`, `summary`, `content`, `tags`).
- `tests` — тесты, привязанные к темам через `topicId`.
- `terms` — термины для словарика.

Подробная инструкция — в `PROJECT.md`.

## Как выложить на GitHub Pages

1. Создай новый репозиторий на GitHub и загрузи в него файлы.
2. Перейди в **Settings → Pages**.
3. В разделе **Build and deployment** выбери:
   - **Source:** Deploy from a branch
   - **Branch:** main, папка **/(root)**
4. Нажми **Save**. Через 1–2 минуты сайт будет доступен.

## AI-юрист

AI-консультант работает через Netlify Function, которая проксирует запросы к OpenRouter. Чтобы он заработал:

1. Добавь переменную `OPENROUTER_API_KEY` в настройки сайта на Netlify.
2. Убедись, что в `js/config.js` указан правильный `AI_PROXY_URL`.
3. Проверь доступность домена `pravolymp.ru` и корректность DNS.

Подробности — в `AI_CONTEXT.md`.

---

## Автоматическая проверка олимпиад

GitHub Actions workflow `.github/workflows/check_olympiads.yml` раз в неделю проверяет сайты олимпиад. Если сайт изменился или недоступен — создаёт issue в репозитории.

Чтобы включить: **Settings → Actions → General** → разрешить Actions, затем во вкладке **Actions** включить workflow «Проверка олимпиад».
